# «Дуэль стихий» — браузерный прототип v0.5.2

Исправления по результатам первого пользовательского теста (17 октября 2026 года).

## Изменения относительно v0.5.1

1. **Управление показом поединка.** Убрано автоматическое продолжение через 3,8/1,8 с. Результат, обе открытые карты и объяснение победы остаются на игровом столе сколько потребуется. **Только нажатие «Продолжить»** выполняет добор и следующий ход, в том числе при поединках ботов и режиме «Быстро».
2. **Удалено дублирование навигации.** В шапке оставлены «Правила» и выход из партии. Кнопки «История дуэлей» и «Памятка стихий» находятся по одной рядом с игровым столом. Для памятки создано отдельное компактное окно; полные правила остаются отдельным экраном.
3. **Текущий счёт.** Под соперниками отображается таблица всех участников: **П** — выигранные дуэли, **Пр** — проигранные, **Н** — ничьи. Ничья учитывается по одному разу для каждого из двух участников и не считается поражением. Статистика строится из реально раскрытых дуэлей и обновляется сразу после вскрытия, включая ботов против ботов. В финале партии есть такая же полная таблица.
4. Уточнено описание порядка добора: первым добирает тот из участников поединка, чей следующий ход наступит раньше.

## Запуск

**Без установки:** скачайте `Duel_Stikhiy_Browser_v0_5_2.zip`, распакуйте полностью в новую папку и откройте `index.html` через Chrome/Edge/Firefox. Все художественные изображения и скрипты находятся в архиве.

**Исходный React/TypeScript-проект:** в `Duel_Stikhiy_Source_v0_5_2.zip`. При наличии Node.js 20+ и интернета: `npm install`, затем `npm run dev` или `npm run build`.

## Проверки

- 19/19 существующих тестов игрового движка.
- 2/2 новых теста подсчёта счёта (в том числе боты против ботов, отдельный учёт ничьих).
- Три полных сценария в Chromium (1, 2, 3 бота; режимы Новичок, Ученик, Мастер), до итогового экрана, с проверкой суммы побед и поражений после каждого раскрытия.
- Проверка в настоящем Chromium: 4,4 секунды при обычной скорости и ещё 2 секунды при ускоренной — открытые карты и статистика не менялись без нажатия «Продолжить».
- Проверено, что панель счёта показывает игрока и всех ботов, а дублирующих кнопок на игровом экране больше нет.

Ограничения: прямое `file://` открытие в автоматизированной среде заблокировано; его предстоит проверить на пользовательском ПК. Стандартная Vite-сборка с `npm install` в среде недоступна, зато автономная сборка и Chromium-тесты выполнены. Сетевого мультиплеера и VK-интеграции нет. Правила игры, стратегии ботов и графика не изменялись.
