# Дуэль стихий

Карточная браузерная игра по миру «Княжича». **Текущая версия: 0.5.2**.  Один человек против 1–3 компьютерных соперников; 48 карт, четыре стихии, открытые дуэли, память карт, счёт побед и поражений.

## Состояние проекта

- `docs/` — **проверенная автономная браузерная сборка v0.5.2**, подготовленная для публикации на GitHub Pages. Работает без npm и сервера.
- `src/` — исходники React/TypeScript; `src/game/` — независимый движок, боты и правила.
- `public/art/` — оптимизированные изображения; `src/game/manifest.json` — каталог карт и учеников.
- `data/manifest.json` — идентичная тестовая копия каталога.
- `test/` — автоматические проверки; `scripts/` — инструменты проверки ассетов и обновления сайта.

⚠️ **Важно:** `docs/` — отдельная опубликованная сборка. Изменения в `src/` не попадут в неё автоматически. После проверенного обновления кода запустите `npm run publish:pages` и закоммитьте обновлённый `docs/`. Не редактируйте собранный HTML вручную.

## Локальный запуск

**Без установки:** откройте `docs/index.html` в браузере.

**Разработка:** Node.js 22.12+ и npm:

```sh
npm install
npm run dev
```

Проверки:

```sh
npm run check:assets
npm test
npm run build
```

Для нового выпуска GitHub Pages:

```sh
npm run publish:pages
git add .
git commit -m "Обновить браузерную версию"
git push
```

## GitHub Pages

1. Создать отдельный публичный репозиторий `socman2023/duel-stikhiy`.
2. Загрузить содержимое проекта в ветку `main`.
3. Открыть **Settings → Pages → Build and deployment → Source: GitHub Actions**.
4. Дождаться успешного выполнения `.github/workflows/pages.yml`.

Адрес после публикации: `https://socman2023.github.io/duel-stikhiy/` (до активации Pages он не работает).

**Важное замечание:** CI для исходников (`ci.yml`) в этой рабочей среде не смог запустить npm-сборку, так как реестр npm был недоступен; при первом пуше обязательно проверять Actions. Опубликованный автономный пакет `docs/` не зависит от npm.

## VK Mini Apps — следующий этап

Игровой движок не зависит от платформы. Для VK Mini Apps запланирована интеграция VK Bridge / VKUI, настройка тем и безопасных зон экрана и проверка во встроенном мобильном браузере. На этом этапе **VK Bridge и VK ID не подключены**. Серверная часть и мультиплеер не планируются для MVP.

## Правила

Основной источник — «ПРАВИЛА ИГРЫ базовая версия.pdf», декабрь 2025; названия и сила карт — печатный «Карты.pdf». Последующие пользовательские решения: добор по одной карте, первым добирает участник дуэли, чья очередь раньше; все игроки видят вскрытие карт в том числе в дуэлях ботов; результат остаётся на столе до нажатия «Продолжить».

## Структура и публикация

`.gitignore` исключает зависимости, временные сборки, локальные настройки и `.env`-файлы. Изображения хранятся в WebP. Для сборки используются относительные пути (`base: './'`) — подходят как для GitHub Pages, так и для будущего VK-хостинга. Публикация и разработка ведутся отдельно от других приложений «Княжича».
